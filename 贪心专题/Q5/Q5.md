# Q5：大头菜商丁丁妹

## 题目信息

- 专题：贪心专题
- 分值：20 分

## 题目描述

虽然丁丁妹惨遭魔法保育协会裁员，但是在某位好心人的帮助下，她采摘到了成色极佳的大头菜，因此销售空前火爆。

现在丁丁妹的大头菜店门口排起了长队，具体而言，共有 `n` 位顾客在排队，编号为 `1 ~ n`，每位顾客购买时间为 `a[i]`。

第 `i` 号顾客的等待时间定义为排在他前面的所有顾客的购买时间之和。

例如：共有 `3` 位顾客，购买时间分别是 `1, 2, 3`。如果按照编号 `2, 1, 3` 的顺序来购买大头菜，则：

```text
2 号顾客等待时间为 0，购买时间为 2
1 号顾客等待时间为 2，购买时间为 1
3 号顾客等待时间为 3，购买时间为 3
```

总等待时间为：

```text
0 + 2 + 3 = 5
```

为了让顾客的购买体验尽可能好，丁丁妹需要设计一种排队次序使得所有顾客的等待时间总和尽可能少。

## 解题思路

这是一道经典的排队等待时间最小化问题。

为了让总等待时间最少，应该让购买时间短的顾客排在前面，也就是按照 `a[i]` 从小到大排序。

可以用相邻交换说明这个贪心策略：

假设有两个相邻顾客，购买时间分别为 `x` 和 `y`，且 `x > y`。

如果顺序是 `x, y`，那么后一个顾客会多等待 `x`。

如果交换为 `y, x`，那么后一个顾客会多等待 `y`。

因为：

```text
y < x
```

所以让购买时间更短的顾客排在前面，总等待时间不会变大。

不断进行这样的交换后，最优队列一定是按购买时间升序排列。

排序后，可以用前缀和模拟等待时间：

```text
prefix = 0
answer = 0
for each time in sorted(a):
    answer += prefix
    prefix += time
```

也可以用贡献法计算。排序后第 `i` 个顾客的购买时间会被后面的顾客等待，所以它对总等待时间的贡献为：

```text
a[i] * (n - i - 1)
```

由于 `n` 最大为 `100000`，`a[i]` 最大为 `10000`，总等待时间可能很大，需要使用 64 位整数保存答案。

## 输入格式

- 第一行：一个正整数 `T`，代表数据组数
- 接下来 `T` 组数据，每组数据格式如下：
  - 第一行：一个正整数 `n`，代表排队的顾客数
  - 第二行：`n` 个正整数 `a[i]`，代表每个顾客的购买时间

## 输出格式

- 输出 `T` 行
- 每行一个整数 `K`，表示最少的等待时间总和

## 数据范围

- `1 <= n <= 100000`
- `1 <= a[i] <= 10000`

## 示例

**输入：**

```text
1 3
1
2
3
```

**输出：**

```text
4
```

## 示例说明

输入等价于：

```text
T = 1
n = 3
a = [1, 2, 3]
```

按照购买时间升序排队：

```text
1, 2, 3
```

三个顾客的等待时间分别为：

```text
0, 1, 3
```

总等待时间为：

```text
0 + 1 + 3 = 4
```
