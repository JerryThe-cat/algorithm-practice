# Q4：清洁工丁丁妹

## 题目信息

- 专题：贪心专题
- 分值：20 分

## 题目描述

庆祝升职活动结束后，走廊上杯盘狼藉，丁丁妹不得不负担起了打扫的重任。

具体而言，需要打扫的走廊一共有 `T` 格，区间范围为 `[1, T]`。

丁丁妹有 `n` 种打扫模式，每种打扫模式仅能使用一次，能够打扫区间 `[L, R]` 内的走廊。

丁丁妹想知道最少使用多少种打扫模式能够将区间 `[1, T]` 的走廊全部打扫完毕，每个格子至少打扫一次。

当然，一个格子可以被打扫多次，打扫的范围也可以超过 `T`，比如 `[1, T + 10]`，只要包含了 `[1, T]` 至少一次即可。

## 解题思路

这是经典的区间覆盖问题。

目标是用最少的区间覆盖完整的 `[1, T]`。

贪心策略：

每次在所有能够接上当前已覆盖部分的区间中，选择右端点 `R` 最大的区间。

设当前已经覆盖到 `cur`，也就是 `[1, cur]` 已经被覆盖。下一步需要覆盖的位置是 `cur + 1`。

因此，可以使用的区间必须满足：

```text
L <= cur + 1
```

在这些区间中，选择 `R` 最大的那个，把 `cur` 更新为这个最大的 `R`。

做法：

1. 将所有区间按照左端点 `L` 从小到大排序
2. 初始时 `cur = 0`，表示还没有覆盖任何位置
3. 扫描所有 `L <= cur + 1` 的区间，找出最大的右端点 `maxR`
4. 如果 `maxR == cur`，说明无法继续覆盖，答案为 `-1`
5. 否则选择一个区间，答案加 `1`，并令 `cur = maxR`
6. 重复上述过程，直到 `cur >= T`

因为每一步都尽可能把覆盖范围向右扩展得最远，所以使用的区间数量最少。

每组数据独立计算答案。

## 输入格式

- 第一行：一个正整数 `CASE`，代表数据组数
- 接下来 `CASE` 组数据，每组数据格式如下：
  - 第一行：两个正整数 `n` 和 `T`，代表打扫模式数与需要打扫的走廊区间右端点
  - 接下来 `n` 行：每行两个正整数 `L, R`，表示第 `i` 种打扫模式能够打扫的走廊区间 `[L, R]`

## 输出格式

- 输出 `CASE` 行
- 每行一个整数 `C`，代表最少使用的打扫模式数
- 如果无论如何都不能打扫完区间 `[1, T]`，输出 `-1`

## 数据范围

- `1 <= n <= 25000`
- `1 <= T <= 10000`
- `1 <= L <= R <= 20000`

## 示例

**输入：**

```text
2
3 5
1 2
2 4
5 5
2 5
1 2
2 4
```

**输出：**

```text
3
-1
```

## 示例说明

第一组数据可以依次选择：

```text
[1, 2]
[2, 4]
[5, 5]
```

最终覆盖完整区间 `[1, 5]`，最少需要 `3` 种打扫模式。

第二组数据中，最多只能覆盖到 `[1, 4]`，无法覆盖位置 `5`，所以输出 `-1`。
