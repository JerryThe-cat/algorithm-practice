# Q2：烤肉man丁丁妹

## 题目信息

- 专题：贪心专题
- 分值：20 分

## 题目描述

丁丁妹和她的妹子们准备去公司野餐，丁丁妹作为团队中的烤肉 man，现在要去市场购买生肉。

现在市场上有 `n` 块生肉，每块生肉有两个属性：美味度 `J[i]` 与重量 `F[i]`。

丁丁妹可以选择让商家割任意重量的肉。例如一块重量为 `3kg` 的肉，丁丁妹可以选择只买 `1.5kg`，当然，肉的美味度也会折半。

更一般地，如果丁丁妹买的肉为 `W1 kg`，肉的原重量为 `W2 kg`，美味度为 `J2`，则丁丁妹买的肉的美味度为：

```text
J2 * W1 / W2
```

丁丁妹最多承重 `M`，请问她买的肉的美味度之和最大是多少？

## 解题思路

因为每块肉都可以购买任意重量，所以这是一个典型的部分背包问题。

对于一块肉，单位重量美味度为：

```text
J[i] / F[i]
```

为了让总美味度最大，应该优先购买单位重量美味度更高的肉。

做法：

1. 计算每块肉的单位重量美味度 `J[i] / F[i]`
2. 按单位重量美味度从高到低排序
3. 依次购买：
   - 如果当前肉的重量不超过剩余承重，就整块购买
   - 如果当前肉的重量超过剩余承重，就只购买剩余承重对应的那一部分，然后结束

由于可以切割肉，只要始终优先选择单位重量价值最高的部分，就不会损失最优性。

最终结果保留三位小数输出。

## 输入格式

- 第一行：两个非负整数 `M` 和 `n`，分别表示最大承重与肉的块数
- 接下来 `n` 行：每行两个正整数 `J[i], F[i]`，分别表示肉的美味度与重量

## 输出格式

- 输出一个浮点数 `C`
- 精确到小数点后 `3` 位，表示丁丁妹买的肉的美味度之和的最大值

## 数据范围

- 所有数值均为不超过 `1000` 的正整数

## 示例

**输入：**

```text
5 3
7 2
4 3
5 2
```

**输出：**

```text
13.333
```

## 示例说明

三块肉的单位重量美味度分别为：

```text
7 / 2 = 3.5
4 / 3 = 1.333...
5 / 2 = 2.5
```

优先购买第 `1` 块肉和第 `3` 块肉：

```text
总重量：2 + 2 = 4
总美味度：7 + 5 = 12
```

还剩 `1kg` 承重，再购买第 `2` 块肉中的 `1kg`：

```text
增加美味度：4 * 1 / 3 = 1.333...
```

最大美味度之和为：

```text
12 + 1.333... = 13.333...
```

保留三位小数后为：

```text
13.333
```
