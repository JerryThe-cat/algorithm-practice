# Q1：调度大师丁丁妹

## 题目信息

- 专题：贪心专题
- 分值：20 分

## 题目描述

丁丁妹转行当程序媛了，公司将次世代操作系统——丁丁 OS（DDOS）的内存调度系统研发重任交给了她。

具体来说，有 `n` 个进程要执行，第 `i` 个进程计算时占用 `R[i]` 的内存，然后会释放一部分，最后的存储结果需要占用 `O[i]` 的内存，其中 `O[i] <= R[i]`。

现在给出 `n` 个进程执行和存储所需的内存，丁丁妹需要设计一套算法，计算执行完所有任务至少需要多少内存。

## 解题思路

假设当前已经执行完若干个进程，它们的结果一共占用了 `sum` 的内存。

此时执行某个进程 `i` 时，需要的内存为：

```text
sum + R[i]
```

执行完后，该进程的结果会留下 `O[i]` 的内存，因此：

```text
sum += O[i]
```

问题的关键是决定进程执行顺序，使整个过程中出现的最大内存占用尽可能小。

对于两个进程 `a` 和 `b`，如果先执行 `a` 再执行 `b`，局部最大内存为：

```text
max(R[a], O[a] + R[b])
```

如果先执行 `b` 再执行 `a`，局部最大内存为：

```text
max(R[b], O[b] + R[a])
```

当：

```text
R[a] - O[a] >= R[b] - O[b]
```

时，先执行 `a` 不会比先执行 `b` 更差。

因此，应该按照 `R[i] - O[i]` 从大到小排序。直观上，`R[i] - O[i]` 越大，表示该进程执行结束后释放的内存越多，越适合放在前面执行。

排序后依次模拟执行过程：

1. `sum` 表示当前已经留下来的存储结果占用
2. 执行进程 `i` 时，用 `sum + R[i]` 更新答案
3. 执行结束后，令 `sum += O[i]`

如果 `n = 0`，没有进程需要执行，答案为 `0`。

## 输入格式

- 第一行：一个整数 `n`，代表进程数
- 接下来 `n` 行：每行两个整数 `R[i], O[i]`

## 输出格式

- 输出一行一个整数，代表执行完所有任务需要的最少内存

## 数据范围

- `0 <= n <= 10^5`
- `0 <= O[i] <= R[i] <= 10^4`

## 示例

**输入：**

```text
2
3 1
4 3
```

**输出：**

```text
5
```

## 示例说明

先执行任务 `1`：

```text
运行时内存占用为 3
结束后存储占用为 1
```

再执行任务 `2`：

```text
运行时内存占用为 1 + 4 = 5
结束后存储占用为 1 + 3 = 4
```

整个过程中最大内存占用为 `5`，因此至少需要大小为 `5` 的内存才能执行完所有程序。
