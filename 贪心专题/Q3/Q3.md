# Q3：活动大师丁丁妹

## 题目信息

- 专题：贪心专题
- 分值：20 分

## 题目描述

丁丁妹由于表现优良，迅速升职，成为了 DDOS 部门的主管。为了庆祝她的升职，丁丁妹计划举办一系列活动。

然而由于只有一间活动房间，她不得不考虑如何安排才能举办最多的活动。

具体而言，有 `n` 个活动，每个活动有一个起始时间 `L` 与终止时间 `R`。

在一个活动举办的时间区间 `[L, R)` 内不能举办其它活动，但一个活动 `i` 的结束点 `R[i]` 可以是另一个活动 `j` 的开始点 `L[j]`。

请问丁丁妹最多能举办多少个活动？

## 解题思路

这是经典的活动选择问题。

为了举办尽可能多的活动，每次应该优先选择结束时间最早的活动。

原因是：结束越早，留给后续活动的时间越多，不会让答案变差。

做法：

1. 将所有活动按照结束时间 `R` 从小到大排序
2. 维护当前已经选择活动的最后结束时间 `lastEnd`
3. 依次扫描排序后的活动：
   - 如果当前活动的开始时间 `L >= lastEnd`，说明它可以接在前一个活动后面，选择它
   - 选择后更新 `lastEnd = R`
4. 统计被选择的活动数量

因为活动区间是 `[L, R)`，结束点不占用房间，所以当 `L == lastEnd` 时，两个活动可以连续举办。

每组数据独立计算答案。

## 输入格式

- 第一行：一个正整数 `T`，表示数据组数
- 接下来 `T` 组数据，每组数据格式如下：
  - 第一行：一个正整数 `n`，表示活动个数
  - 接下来 `n` 行：每行两个正整数 `L, R`，表示活动的开始和终止时间

## 输出格式

- 输出 `T` 行
- 每行一个整数 `C`，表示丁丁妹最多能举办的活动数

## 数据范围

- `1 <= n <= 10^5`
- `1 <= L <= R <= 10^4`

## 示例

**输入：**

```text
1
3
1 2
2 3
2 4
```

**输出：**

```text
2
```

## 示例说明

可以选择活动：

```text
[1, 2)
[2, 3)
```

第一个活动在 `2` 时刻结束，第二个活动也在 `2` 时刻开始。由于区间为 `[L, R)`，它们不会冲突。

因此最多能举办 `2` 个活动。
