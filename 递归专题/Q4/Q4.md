# Q4：全排列

## 题目描述

给定正整数 N，输出 1 到 N 所有数字的全排列，每个排列占一行。

## 解题思路

使用**递归回溯**枚举所有排列：

1. 维护一个待选数字列表 `remain`（初始为 `[1, 2, ..., N]`）和当前已拼接的数字 `path`。
2. 每次从 `remain` 中选一个数字加入 `path`，并从 `remain` 中移除该数字，递归处理剩余数字。
3. 终止条件：`remain` 为空时，将 `path` 加入结果列表。
4. 排列以整数形式存储（如 1、2、3 的某个排列存为 `123`）。

## 输入格式

- 一行：一个正整数 N

## 输出格式

- 共 N! 行，每行一个整数，表示一种排列（按递归生成顺序输出）

## 示例

**输入：**
```
3
```

**输出：**
```
123
132
213
231
312
321
```
