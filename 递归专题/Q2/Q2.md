# Q2：树的最大深度

## 题目描述

给定一棵有 n 个节点的有根树，通过 n-1 条有向边（父 → 子）来描述树的结构，求该树的最大深度。

## 解题思路

使用递归（DFS）求树的最大深度：

1. **建图**：读入 n-1 条边，分别记录每个节点的子节点列表（`children`）和父节点（`parents`）。
2. **找根节点**：没有父节点的节点即为根节点。
3. **递归求深度**：
   - 终止条件：若当前节点是叶子节点（无子节点），返回深度 1。
   - 递归调用：对每个子节点递归求深度，取最大值。
   - 返回值：`max(子树深度) + 1`。

## 输入格式

- 第一行：一个整数 n，表示节点数（节点编号为 1 ~ n）
- 接下来 n-1 行：每行两个整数 a 和 b，表示 a 是 b 的父节点

## 输出格式

- 一行：一个整数，表示树的最大深度

## 示例

**输入：**
```
5
1 2
1 3
2 4
2 5
```

**输出：**
```
3
```
