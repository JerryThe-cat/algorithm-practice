# Q3：子集和判断

## 题目描述

给定 n 个整数，判断其中是否存在某个子集，使得子集中所有元素之和恰好等于 k。

## 解题思路

使用**位运算枚举所有子集**：

1. n 个元素共有 `2^n` 个子集，用一个 n 位的二进制数（掩码 mask）来表示每种子集。
2. 对每个 mask，遍历每一位：若第 i 位为 1，则将第 i 个元素加入当前子集的总和。
3. 若某个子集的总和等于 k，输出 `YE5`，提前退出；若所有子集都不满足，输出 `N0`。

> 注意：输出为 `YE5`（数字5）和 `N0`（数字0），并非常规的 YES/NO。

## 输入格式

- 第一行：两个整数 n 和 k，n 为元素个数，k 为目标和
- 接下来 n 行：每行一个整数，表示数组中的元素

## 输出格式

- 一行：若存在满足条件的子集输出 `YE5`，否则输出 `N0`

## 示例

**输入：**
```
4 7
1
3
5
2
```

**输出：**
```
YE5
```
