# Q5：魔法师丁丁妹

## 题目信息

- 专题：回溯专题
- 分值：20 分

## 题目描述

丁丁妹最近在学习奇妙的化学反应。

具体而言，丁丁妹现在有 `n` 个反应方程式，表现方式为一个长度为 `k` 的、仅包含小写字母的字符串：

```text
a0 a1 ... a(k-1)
```

这个方程式表示物质 `a0` 经过中间变换 `a1, a2, ..., a(k-2)`，最终变换为物质 `a(k-1)`。

现在丁丁妹想要把物质 `b` 变换为物质 `m`，她想要知道通过给定的 `n` 个反应方程式可不可以做到。

## 解题思路

每个反应方程式只需要关注起点和终点：

```text
字符串首字母 -> 字符串尾字母
```

例如：

```text
bark
```

表示可以从物质 `b` 变换到物质 `k`。

因此，本题可以抽象成一个有向图：

- 每个小写字母是一种物质
- 每个反应方程式是一条有向边
- 问题变为判断是否存在一条从 `b` 到 `m` 的路径

可以使用 DFS 回溯搜索。

## 回溯过程

设 `visited[x]` 表示物质 `x` 是否已经搜索过，避免在环中无限递归。

DFS 过程：

1. 从物质 `b` 开始搜索
2. 如果当前物质是 `m`，说明可以完成变换
3. 否则枚举当前物质能够通过反应到达的所有下一种物质
4. 对没有访问过的物质继续 DFS
5. 如果某条路径能够到达 `m`，输出 `Yes.`
6. 如果所有路径都不能到达 `m`，输出 `No.`

由于只有 `26` 个小写字母，搜索规模很小。

## 输入格式

- 第一行：一个整数 `T`，代表数据组数
- 接下来 `T` 组数据，每组数据格式如下：
  - 第一行：一个整数 `n`，代表反应方程式的个数
  - 接下来 `n` 行：每行一个长度不超过 `50` 的、仅包含小写字母的字符串，表示反应方程式

## 输出格式

- 输出 `T` 行
- 对于每组数据：
  - 如果丁丁妹能够把物质 `b` 变换为物质 `m`，输出 `Yes.`
  - 否则输出 `No.`

注意：`Yes.` 和 `No.` 后面都有英文句点。

## 数据范围

- `1 <= n <= 20`
- 每个反应方程式长度不超过 `50`
- 字符串仅包含小写字母

## 示例

**输入：**

```text
1
5
bark
kawaii
kimo
ohhhh
hmmm
```

**输出：**

```text
Yes.
```

## 示例说明

这些反应方程式对应的关键变换为：

```text
bark   : b -> k
kawaii : k -> i
kimo   : k -> o
ohhhh  : o -> h
hmmm   : h -> m
```

丁丁妹可以通过：

```text
bark -> kimo -> ohhhh -> hmmm
```

实现：

```text
b -> k -> o -> h -> m
```

因此输出 `Yes.`。
