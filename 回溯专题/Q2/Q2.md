# Q2：摇钱树

## 题目信息

- 专题：回溯专题
- 分值：20 分

## 题目描述

520 马上就要到了，丁丁妹在思考送自己的室友什么礼物能够彰显她深深的室友之爱。

由于丁丁妹最近沉迷于种树，于是她决定送一颗摇钱树。

具体而言，这颗摇钱树有 `n` 个节点，编号为 `1 ~ n`，根节点编号为 `1`。

丁丁妹在每个节点上都挂了一些钱，每次摇一个节点，以该节点为根的子树上的钱全部都会掉下来。

现在丁丁妹很好奇摇不同的节点会掉下多少钱来，请你来帮助她解决这个问题。

## 解题思路

这题可以用 DFS 预处理每个节点的子树权值和。

因为树的根节点固定为 `1`，所以从节点 `1` 开始深度优先搜索。

设：

```text
sum[u] 表示以 u 为根的子树中所有节点的钱数之和
val[u] 表示 u 节点上挂的钱数
```

初始化：

```text
sum[u] = val[u]
```

然后递归遍历 `u` 的每个子节点 `v`，把子树结果累加回来：

```text
sum[u] += sum[v]
```

由于输入给出的是无向边，DFS 时需要记录父节点 `parent`，避免从子节点又走回父节点。

预处理完成后，每个询问 `x` 的答案就是：

```text
sum[x]
```

因此：

- 预处理复杂度为 `O(n)`
- 每次询问复杂度为 `O(1)`

## 回溯过程

DFS 过程可以理解为：

1. 进入节点 `u`
2. 先把 `u` 自己的钱数加入 `sum[u]`
3. 递归处理所有没有访问过的相邻节点
4. 子节点递归结束后，将子节点的子树和加到 `sum[u]`
5. 返回上一层

这种“进入节点、递归子节点、回到父节点累加结果”的过程就是树上的回溯。

## 输入格式

- 第一行：两个整数 `n, m`，代表摇钱树的节点个数以及询问个数
- 第二行：`n` 个数字，表示每个节点上挂的钱数
- 接下来 `n - 1` 行：每行两个整数 `x, y`，表示摇钱树上的一条边
- 接下来 `m` 行：每行一个整数 `x`，表示询问摇以 `x` 为根的子树能掉下来多少钱

## 输出格式

- 输出 `m` 行
- 每行一个数字 `C`，对应一个询问的答案

## 数据范围

- `m <= n <= 10^4`
- `val[i] <= 1000`

## 示例

**输入：**

```text
3 3
1 2 3
2 1
1 3
1
2
3
```

**输出：**

```text
6
2
3
```

## 示例说明

这棵树以 `1` 为根：

```text
    1
   / \
  2   3
```

每个节点的钱数分别为：

```text
val[1] = 1
val[2] = 2
val[3] = 3
```

所以：

```text
sum[1] = 1 + 2 + 3 = 6
sum[2] = 2
sum[3] = 3
```
