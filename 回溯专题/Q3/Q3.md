# Q3：马的遍历

## 题目信息

- 专题：回溯专题
- 分值：20 分

## 题目描述

众所周知，在象棋中马的行走方式如下：

```text
X O X O X
O X X X O
X X H X X
O X X X O
X O X O X
```

其中 `H` 代表马的位置，`O` 代表马走一步能到达的位置。

请你找一条路径，让马能够经过所有的方格刚好一次。

注意，马的起点和终点可以在棋盘上的任何点，棋盘编号规则如图所示。

![棋盘编号规则](knight-board-example.png)

## 解题思路

这是一个搜索棋盘上哈密顿路径的问题，可以使用回溯。

棋盘大小为 `n × m`，其中：

- 行号为 `1 ~ n`
- 列号用大写字母表示，依次为 `A, B, C, ...`
- 坐标写成“列字母 + 行号”的形式，例如 `A1`、`B3`

由于马的起点可以是任意格子，为了得到字典序最小的路径，需要：

1. 按坐标字典序从小到大枚举起点
2. 在每一步搜索时，也按坐标字典序从小到大尝试下一步
3. 一旦找到第一条能遍历所有格子的路径，就可以直接输出

马在棋盘上的移动有 `8` 个方向：

```text
(+1, +2), (+2, +1), (+2, -1), (+1, -2),
(-1, -2), (-2, -1), (-2, +1), (-1, +2)
```

实际搜索时，需要过滤掉越界或已经访问过的格子。

## 回溯过程

设 `path` 表示当前路径，`visited` 表示某个格子是否已经走过。

DFS 过程：

1. 选择一个起点，将它加入 `path`
2. 标记起点已经访问
3. 如果 `path` 长度等于 `n * m`，说明已经经过所有格子，搜索成功
4. 否则枚举当前格子能到达的所有下一步
5. 按坐标字典序排序这些下一步
6. 对每个合法下一步：
   - 加入路径
   - 标记访问
   - 继续 DFS
   - 如果成功，直接返回
   - 如果失败，撤销选择并尝试下一个位置

如果所有起点都无法找到完整路径，则输出 `impossible`。

由于 `n * m <= 26`，回溯搜索在配合字典序剪枝后可以处理。

## 输入格式

- 单组数据，第一行为两个整数 `n, m`，描述棋盘大小

## 输出格式

- 输出一条马遍历完棋盘上所有格点的路径
- 如果路径有多条，输出字典序最小的那条
- 如果不存在这样的路径，输出 `impossible`

路径输出时，相邻坐标之间不加空格。

## 数据范围

- `n * m <= 26`

## 示例 1

**输入：**

```text
4 3
```

**输出：**

```text
A1B3C1A2B4C2A3B1C3A4B2C4
```

## 示例 2

**输入：**

```text
2 3
```

**输出：**

```text
impossible
```

## 示例说明

对于 `4 × 3` 的棋盘，一条合法路径为：

```text
A1 -> B3 -> C1 -> A2 -> B4 -> C2 -> A3 -> B1 -> C3 -> A4 -> B2 -> C4
```

每一步都符合马的移动规则，并且刚好经过全部 `12` 个格子一次。
