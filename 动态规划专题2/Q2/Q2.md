# Q2：大头菜育种专家丁丁妹

## 题目信息

- 专题：动态规划专题 2
- 分值：20 分

## 题目描述

多亏了好心人帮助丁丁妹安排合理的大头菜购买顺序，大头菜顺利售罄，丁丁妹也赚得盆满钵满。

可是丁丁妹深知“金山银山不如绿水青山”的道理，秉持着可持续发展的理念，丁丁妹决定回馈自然，在山上种满大头菜。

现在丁丁妹手上有 `n` 枚大头菜种子，每一枚都有 `p[i]` 的概率萌芽。现在丁丁妹想知道，恰好 `k` 枚大头菜种子萌芽的概率是多少？

丁丁妹再次用大头菜诱惑你为她解决问题，虽然你实在不想帮忙了，可是大头菜实在太香了，因此你还是决定帮丁丁妹解决问题。

## 解题思路

这是一个概率动态规划问题，可以看作每枚种子都有两种状态：

1. 萌芽，概率为 `p[i]`
2. 不萌芽，概率为 `1 - p[i]`

设 `dp[j]` 表示已经处理若干枚种子后，恰好有 `j` 枚种子萌芽的概率。

初始状态：

```text
dp[0] = 1
```

表示还没有处理任何种子时，恰好 `0` 枚种子萌芽的概率为 `1`。

处理第 `i` 枚种子时，如果它的萌芽概率为 `p[i]`，则：

```text
dp[j] = dp[j] * (1 - p[i]) + dp[j - 1] * p[i]
```

含义是：

- 原来已经有 `j` 枚萌芽，第 `i` 枚不萌芽
- 原来已经有 `j - 1` 枚萌芽，第 `i` 枚萌芽

使用一维数组优化时，`j` 需要从大到小倒序枚举，避免当前种子的结果影响同一轮转移。

如果 `k > n`，不可能恰好有 `k` 枚种子萌芽，答案为 `0`。

最终答案为 `dp[k]`。

## 输入格式

- 第一行：两个非负整数 `n` 和 `k`
- 第二行：`n` 个小数 `p[i]`，表示每枚大头菜种子的萌芽概率

## 输出格式

- 输出恰好 `k` 枚大头菜种子萌芽的概率
- 结果四舍五入保留四位小数

## 数据范围

- `0 <= n <= 200`
- `0 <= k <= 100`

## 示例

**输入：**

```text
3 2
0.5 0.25 0.75
```

**输出：**

```text
0.4062
```

## 示例说明

恰好两枚种子萌芽有三种情况：

```text
第 1、2 枚萌芽，第 3 枚不萌芽：0.5 * 0.25 * 0.25 = 0.03125
第 1、3 枚萌芽，第 2 枚不萌芽：0.5 * 0.75 * 0.75 = 0.28125
第 2、3 枚萌芽，第 1 枚不萌芽：0.25 * 0.75 * 0.5 = 0.09375
```

总概率为：

```text
0.03125 + 0.28125 + 0.09375 = 0.40625
```

四舍五入保留四位小数后为：

```text
0.4062
```
