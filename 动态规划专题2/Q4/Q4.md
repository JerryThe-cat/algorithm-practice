# Q4：字符串权值和最大

## 题目信息

- 专题：动态规划专题 2
- 分值：20 分

## 题目描述

一个长度为 `n` 的只包含小写字母的字符串，每个字母分别对应着一个 `1 ~ 26` 之间的整数。

请你将 `1 ~ 26` 分配给这些字母，让它们的权值和最大。

比如对于字符串 `qaq`，可以把 `26` 分配给 `q`，`25` 分配给 `a`，这样这个字符串权值和为：

```text
26 + 25 + 26 = 77
```

## 解题思路

一个字母对总权值的贡献为：

```text
该字母出现次数 * 分配给该字母的权值
```

因此，为了让总权值最大，出现次数越多的字母应该分配越大的权值。

做法：

1. 统计字符串中每个小写字母的出现次数
2. 将出现次数从大到小排序
3. 依次分配权值 `26, 25, 24, ...`
4. 累加 `出现次数 * 当前权值`

如果两个字母出现次数相同，它们之间的分配顺序不影响最终答案。

如果字符串长度为 `0`，则没有任何字母，最大权值和为 `0`。

## 输入格式

- 单组数据，一行长度为 `n` 的字符串

## 输出格式

- 输出一行一个整数 `K`，表示字符串的最大权值和

## 数据范围

- `0 <= n <= 10000`
- 字符串只包含小写字母

## 示例

**输入：**

```text
abc
```

**输出：**

```text
75
```

## 示例说明

字符串 `abc` 中，`a`、`b`、`c` 各出现一次。

任选三个字母分别分配最大的三个权值 `26`、`25`、`24`，最大权值和为：

```text
26 + 25 + 24 = 75
```
