# Q1：大头菜农丁丁妹

## 题目信息

- 专题：动态规划专题 2
- 分值：20 分

## 题目描述

由于开发的动物森友会销量不佳，差评如潮，魔法保育员丁丁妹被魔法保育协会裁员了。

但是，丁丁妹也要恰饭的嘛。恰逢大头菜价格暴涨，丁丁妹看准机会买下了一块大小为 `N × M` 的大头菜田，准备靠大头菜东山再起。

然而，大头菜也有成色好坏之分，而由于丁丁妹先天残疾，她在田里采摘大头菜时每次只能往下走或者往右走。

丁丁妹已经穷得吃不起饭了，所以请你可怜可怜她，帮助她计算一下从左上角走到右下角能够采摘到的大头菜成色值之和最大是多少？

## 解题思路

这是一个典型的网格路径动态规划问题。

因为丁丁妹每次只能向下或向右走，所以到达位置 `(i, j)` 之前，只可能来自：

1. 上方 `(i - 1, j)`
2. 左方 `(i, j - 1)`

设 `dp[i][j]` 表示从左上角 `(1, 1)` 走到 `(i, j)` 时，能够获得的最大成色值之和。

状态转移方程为：

```text
dp[i][j] = beauty[i][j] + max(dp[i - 1][j], dp[i][j - 1])
```

边界情况：

- `dp[1][1] = beauty[1][1]`
- 第一行只能从左边走来
- 第一列只能从上边走来

由于成色值可能为负数，不能简单地把未到达状态初始化为 `0`，否则会影响最大值判断。

最终答案为 `dp[N][M]`。

## 输入格式

- 第一行：两个整数 `N` 和 `M`，表示大头菜田的行数和列数
- 接下来 `N` 行：每行 `M` 个整数，表示矩阵中每个位置的大头菜成色值 `beauty[i][j]`

## 输出格式

- 输出一个整数 `K`，表示从左上角 `(1, 1)` 走到右下角 `(N, M)` 能够采摘到的大头菜成色值之和的最大值

## 数据范围

- `0 <= N <= 200`
- `0 <= M <= 200`
- `-200 <= beauty[i][j] <= 200`

## 示例

**输入：**

```text
3 3
1 4 5
4 1 6
1 1 1
```

**输出：**

```text
17
```

## 示例说明

一种最优路线为：

```text
1 -> 4 -> 5 -> 6 -> 1
```

成色值之和为：

```text
1 + 4 + 5 + 6 + 1 = 17
```
