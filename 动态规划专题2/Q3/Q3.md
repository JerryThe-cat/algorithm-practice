# Q3：数学家丁丁妹

## 题目信息

- 专题：动态规划专题 2
- 分值：20 分

## 题目描述

大头菜致富后，丁丁妹时常坐在田埂上思考人生。有一天，她在大头菜田边休息时，想到这样一个问题：有 `N` 颗大头菜，符合如下要求：

1. 每颗大头菜的成色值在 `[L, R]` 范围内
2. 所有的大头菜成色值之和是 `3` 的倍数

这 `N` 颗大头菜的成色值有多少种符合条件的组合呢？

显然，这对于丁丁妹来说实在太难了，可是丁丁妹实在是想知道答案，因此她花重金聘请了你来解决这个问题。

另外，由于丁丁妹的脑容量只有 `2048KB`，因此你需要在这个空间限制内解决问题。

## 解题思路

样例中 `[1, 2]` 和 `[2, 1]` 被算作两种方案，因此本题统计的是长度为 `N` 的有序序列数量。

因为只关心总和是否是 `3` 的倍数，所以不需要记录具体的成色值，只需要记录每个数对 `3` 取模后的余数。

先统计区间 `[L, R]` 中对 `3` 取模分别为 `0`、`1`、`2` 的数的个数：

```text
cnt[0], cnt[1], cnt[2]
```

设 `dp[r]` 表示已经选择若干颗大头菜后，当前成色值之和对 `3` 取模为 `r` 的方案数。

初始状态：

```text
dp[0] = 1
dp[1] = 0
dp[2] = 0
```

每次新增一颗大头菜时，根据新选成色值的余数进行转移：

```text
new[0] = dp[0] * cnt[0] + dp[1] * cnt[2] + dp[2] * cnt[1]
new[1] = dp[0] * cnt[1] + dp[1] * cnt[0] + dp[2] * cnt[2]
new[2] = dp[0] * cnt[2] + dp[1] * cnt[1] + dp[2] * cnt[0]
```

每一轮转移后都要对 `10^9 + 7` 取模。

由于任意时刻只需要保存余数为 `0`、`1`、`2` 的方案数，所以空间复杂度为 `O(1)`，满足 `2048KB` 的空间限制。

最终答案为 `dp[0]`。

## 输入格式

- 单组数据，一行三个整数 `N`、`L`、`R`

## 输出格式

- 输出符合条件的大头菜成色值组合数
- 答案对 `10^9 + 7` 取模

## 数据范围

- `1 <= N <= 2 * 10^5`
- `1 <= L <= R <= 10^9`

## 示例

**输入：**

```text
2 1 3
```

**输出：**

```text
3
```

## 示例说明

区间 `[1, 3]` 中可以选择的成色值为 `1`、`2`、`3`。

当 `N = 2` 时，成色值之和为 `3` 的倍数的有序组合为：

```text
[1, 2]
[2, 1]
[3, 3]
```

因此答案为 `3`。
