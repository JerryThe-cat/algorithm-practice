# Q5：没有上司的舞会

## 题目信息

- 专题：动态规划专题 2
- 分值：20 分

## 题目描述

有 `N` 名职员，编号为 `1 ~ N`。他们的关系就像一棵以总经理为根的树，父节点就是子节点的直接上司。

每个职员有一个快乐指数，用整数 `H[i]` 给出，其中 `1 <= i <= N`。

现在要召开一场周年庆宴会，不过，没有职员愿意和直接上司一起参会。在满足这个条件的前提下，主办方希望邀请一部分职员参会，使得所有参会职员的快乐指数总和最大，求这个最大值。

## 解题思路

这是一道经典的树形动态规划问题。

对于每个职员 `u`，只有两种选择：

1. 邀请 `u` 参会
2. 不邀请 `u` 参会

设：

```text
dp[u][0] 表示不邀请 u 时，以 u 为根的子树能获得的最大快乐指数
dp[u][1] 表示邀请 u 时，以 u 为根的子树能获得的最大快乐指数
```

状态转移：

如果邀请 `u`，那么 `u` 的直接下属都不能被邀请：

```text
dp[u][1] = H[u] + sum(dp[v][0])
```

其中 `v` 是 `u` 的直接下属。

如果不邀请 `u`，那么每个直接下属 `v` 可以邀请，也可以不邀请，取较大值：

```text
dp[u][0] = sum(max(dp[v][0], dp[v][1]))
```

先根据上下级关系建树，再找到没有上司的职员作为根节点，从根节点开始 DFS 计算 DP。

最终答案为：

```text
max(dp[root][0], dp[root][1])
```

由于快乐指数可能为负数，如果所有邀请方案都不优，选择不邀请某些人可以避免负贡献。

## 输入格式

- 第一行：一个整数 `N`
- 接下来 `N` 行：第 `i` 行表示 `i` 号职员的快乐指数 `H[i]`
- 接下来 `N - 1` 行：每行两个整数 `L, K`，表示 `K` 是 `L` 的直接上司

注意：后一个数是前一个数的父节点，不要把边的方向建反。

## 输出格式

- 输出最大的快乐指数

## 数据范围

- `1 <= N <= 6000`
- `-128 <= H[i] <= 127`

## 示例

**输入：**

```text
7
1
1
1
1
1
1
1
1 3
2 3
6 4
7 4
4 5
3 5
```

**输出：**

```text
5
```

## 示例说明

树的根节点是 `5`。

一种最优邀请方案是邀请：

```text
1, 2, 5, 6, 7
```

这些职员之间不存在直接上下级关系，快乐指数总和为：

```text
1 + 1 + 1 + 1 + 1 = 5
```
