# Q8：组合和为质数的个数

## 题目描述

从 n 个整数中选出 m 个，统计所有满足条件的组合中，元素之和为质数的组合共有多少个。

## 解题思路

使用**递归枚举组合**：

1. 定义 `select(m, nums, add, sum)`：
   - `m`：还需要再选几个数
   - `nums`：当前可选的数字列表（每次传入当前元素之后的子列表，保证不重复选）
   - `add`：当前已选元素的累计和
   - `sum`：存储所有完整组合之和的列表
2. 终止条件：`m == 0` 时，将当前累计和加入结果列表。
3. 递归调用：枚举当前可选列表中的每个元素，将其加入累计和，并递归选剩余的数。

枚举完所有组合后，使用 `sympy.isprime` 逐一判断每个组合的和是否为质数，统计质数个数。

## 输入格式

- 第一行：两个整数 n 和 m，n 为数组长度，m 为选取个数
- 第二行：n 个整数，用空格分隔

## 输出格式

- 一行：一个整数，表示和为质数的组合个数

## 示例

**输入：**
```
4 2
1 2 3 4
```

**输出：**
```
4
```

> 所有 C(4,2)=6 种组合及其和：1+2=3✓, 1+3=4✗, 1+4=5✓, 2+3=5✓, 2+4=6✗, 3+4=7✓，共 4 个质数。
