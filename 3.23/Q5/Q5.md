# Q5：汉诺塔

## 题目描述

经典汉诺塔问题：将 N 个从小到大叠放在柱 A 上的圆盘，全部移动到柱 C 上，柱 B 作为辅助柱。要求大盘始终在小盘下方。输出总移动次数及每一步的详细信息。

## 解题思路

使用经典**递归**解法，并额外追踪每个盘子的编号（编号越大盘子越大）：

- `move(remain_plates, disk_id, counts, direction, path)`
  - `remain_plates`：当前待移动的盘子数量
  - `disk_id`：当前最大盘子的编号
  - `counts`：全局计步器（用列表包装以便在递归中修改）
  - `direction`：`[start, end]`，表示从哪根柱移到哪根柱
  - `path`：记录每一步的详细信息

**递归逻辑：**
1. 终止条件：只剩 1 个盘子，直接移动并记录。
2. 递归步骤：
   - 将上面 `remain_plates - 1` 个盘从起始柱移到辅助柱。
   - 将最大盘（编号 `disk_id`）从起始柱移到目标柱。
   - 将上面 `remain_plates - 1` 个盘从辅助柱移到目标柱。

## 输入格式

- 一行：一个正整数 N，表示盘子数量

## 输出格式

- 第一行：一个整数，表示总移动次数（即 2^N - 1）
- 接下来每行格式：`step X: Y From A To B`
  - X 为步骤编号，Y 为盘子编号，A 为源柱，B 为目标柱

## 示例

**输入：**
```
3
```

**输出：**
```
7
step 1: 1 From A To C
step 2: 2 From A To B
step 3: 1 From C To B
step 4: 3 From A To C
step 5: 1 From B To A
step 6: 2 From B To C
step 7: 1 From A To C
```
