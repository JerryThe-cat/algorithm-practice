# Q7：整数划分（双参数版）

## 题目描述

给定正整数 n 和 m，求将 n 拆分为各部分均不超过 m 的正整数之和的方案总数。

## 解题思路

与 Q6 的递推思路完全相同，定义 `dp(n, m)` 为：将 n 拆分为各部分均不超过 m 的方案数。

**递推关系：**
- `n == 1` 或 `m == 1`：只有 1 种方案，返回 1。
- `n < m`：转化为 `dp(n, n)`。
- `n == m`：`dp(n, m-1) + 1`（+1 代表 n 本身单独成一组的方案）。
- `n > m`：`dp(n-m, m) + dp(n, m-1)`。

与 Q6 的区别在于：**Q6 由程序自动以 n 作为上限调用**，而 **Q7 由用户直接指定 m**，因此适用于"最大划分值受限"的场景。

本题支持**多组输入**，每行两个整数。

## 输入格式

- 多行，每行两个正整数 n 和 m，用空格分隔

## 输出格式

- 每行输出对应的方案总数

## 示例

**输入：**
```
5 3
6 4
```

**输出：**
```
5
9
```
