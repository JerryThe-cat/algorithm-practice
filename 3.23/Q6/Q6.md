# Q6：整数划分（单参数版）

## 题目描述

给定正整数 n，求将 n 拆分为若干正整数之和的方案总数（不计顺序，即整数分拆数）。

## 解题思路

使用**递归**，定义 `division(n, m)` 为：将 n 拆分为各部分均不超过 m 的方案数。

**递推关系：**
- `n == 1` 或 `m == 1`：只有一种方案，返回 1。
- `n < m`：最大值不可能超过 n，转化为 `division(n, n)`。
- `n == m`：可以包含 m 本身（即 n 自身单独一组），方案数 = `division(n, m-1) + 1`。
- `n > m`：分两类，最大部分恰好为 m 的方案（`division(n-m, m)`）加上最大部分小于 m 的方案（`division(n, m-1)`）。

调用入口为 `division(n, n)`（最大划分值不超过 n 本身）。

本题支持**多组输入**，每行一个整数。

## 输入格式

- 多行，每行一个正整数 n

## 输出格式

- 每行输出对应 n 的整数划分方案总数

## 示例

**输入：**
```
4
5
6
```

**输出：**
```
5
7
11
```
